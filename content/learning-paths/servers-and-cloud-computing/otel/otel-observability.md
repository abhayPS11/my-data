# 📊 OpenTelemetry on Arm (GCP SUSE ARM64) – Learning Path (Part 2: Observability Stack & Telemetry Pipeline)

---

## 🎯 Learning Outcome

Deploy and connect OpenTelemetry Collector, Prometheus, and Jaeger to collect, store, and visualize telemetry data generated by the Flask microservice running on ARM64 infrastructure.

---

## 📌 Complete Architecture

```
Flask Microservice (ARM)
        |
        | OpenTelemetry SDK
        v
OpenTelemetry Collector
   |            |
Metrics → Prometheus
Traces  → Jaeger
```

---

## 🔓 Required Firewall Ports (Part 2)

| Service           | Port  | Purpose                    |
| ----------------- | ----- | -------------------------- |
| Prometheus        | 9090  | Metrics UI                 |
| Jaeger UI         | 16686 | Traces UI                  |
| Collector Metrics | 8889  | Prometheus scrape endpoint |
| OTLP gRPC         | 4317  | Telemetry ingestion        |
| OTLP HTTP         | 4318  | Telemetry ingestion        |

# 📡 Step 7: Create OpenTelemetry Collector Configuration

### Summary

Configures how telemetry is received from the application and exported to Prometheus and Jaeger.

```bash
nano otel-collector-config.yaml
```

### 📄 otel-collector-config.yaml

```yaml
receivers:
  otlp:
    protocols:
      grpc:
        endpoint: 0.0.0.0:4317
      http:
        endpoint: 0.0.0.0:4318

exporters:
  otlp:
    endpoint: jaeger:4317
    tls:
      insecure: true

  prometheus:
    endpoint: 0.0.0.0:8889

service:
  pipelines:
    traces:
      receivers: [otlp]
      exporters: [otlp]

    metrics:
      receivers: [otlp]
      exporters: [prometheus]
```

# 📊 Step 8: Create Prometheus Configuration

### Summary

Sets Prometheus to scrape metrics exposed by the OpenTelemetry Collector.

```bash
nano prometheus.yml
```

### 📄 prometheus.yml

```yaml
global:
  scrape_interval: 5s

scrape_configs:
  - job_name: "otel-collector"
    static_configs:
      - targets: ["otel-collector:8889"]
```

# 🧱 Step 9: Create Docker Compose Stack

### Summary

Defines and orchestrates all observability components along with the Flask service.

```bash
nano docker-compose.yml
```

### 📄 docker-compose.yml

```yaml
services:
  otel-demo-app:
    build: .
    ports:
      - "8080:8080"
    depends_on:
      - otel-collector

  otel-collector:
    image: otel/opentelemetry-collector-contrib:latest
    command: ["--config=/etc/otel-collector-config.yaml"]
    volumes:
      - ./otel-collector-config.yaml:/etc/otel-collector-config.yaml
    ports:
      - "4317:4317"
      - "4318:4318"
      - "8889:8889"

  jaeger:
    image: jaegertracing/all-in-one:latest
    ports:
      - "16686:16686"

  prometheus:
    image: prom/prometheus:latest
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml
    command:
      - "--config.file=/etc/prometheus/prometheus.yml"
    ports:
      - "9090:9090"
```

### Summary

Builds the Flask image and starts all telemetry services.


Verify running containers:


Expected services:

* otel-demo-app
* otel-collector
* jaeger
* prometheus
